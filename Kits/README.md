# Kits/

Drop your modular kit JSON files here. The Level Builder addon scans this
folder when the editor loads, and again when you click **Reload Kits From
Disk** in the **Modular** tab of the **Level Builder** window.

See [`../Documentation/Artists/GettingStarted.md`](../Documentation/Artists/GettingStarted.md)
for the JSON schema and a step-by-step guide.

`ExampleDungeonKit.json` is included as a starting point — duplicate it and
edit the names / asset references / sockets to match your own art.
